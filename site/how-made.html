Behind the captures

How these images and videos were made

The product overview uses original illustrated animation. The interface demos and screenshots render Chimera's actual React components and app state in a local browser. Their Atlas project, people, tasks, notes and resource figures are fictional.

Product images

The screenshots render the production screens with a local fixture that supplies their data. They show the interface without connecting to personal accounts, a live daemon or a provider. Secret entries contain names and masked states only. The homepage hero has an illustrated overview poster; the context handoff remains available among the interface demos.

The desktop monitor is a real component. Its Atlas pricing preview is a synthetic SVG drawn by the fixture; ownership, actions and status are scripted. No desktop was captured or controlled.

Product videos

The 90-second product overview is a conceptual Canvas animation: flying cards, drawn connections, dependency lanes and illustrated diffs explain capability families. It is not real UI or a recording of agents working. Its timeline is sampled at 30 frames per second, at 1600×1000. Desktop control is macOS only; availability varies by platform and provider, as described in the feature guide. Snapshot branches are explicit saved-context handoffs, not native provider session forks.

The eleven interface demos use real clicks, keystrokes and focus changes in those components. A scripted fixture answers RPC requests and replays task states; the films do not record agents executing work.

Camera moves, pointer motion, captions and timing are editorial. The interface demos are sampled at 15 frames per second. All twelve films are silent. Durations and resource figures are not performance measurements.

Playback starts when you choose it. Native controls, English captions, static posters and text steps remain available without JavaScript. Expand the player to inspect small interface text, or use the static alternatives for reduced motion.
